What this covers:
Scenario:
A furniture retailer needs a browser-based page that allows a sales consultant to capture a customer order, calculate the total, apply a member discount where relevant, and display and manage the order status. The solution must validate user input, use readable JavaScript and demonstrate practical browser interaction.
